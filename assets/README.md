# 图片资源

文档配图统一放这里，用相对路径引用。

## 命名

`产品线-内容-序号.扩展名`，例如 `fr3-work-envelope-01.png`、`revamp-pipeline-02.png`。

不要用截图工具默认的 `CleanShot 2026-11-20 at 15.07.32.png` 这类名字，分享出去链接会很难看，也不方便替换。

## 尺寸

- 正文配图宽度控制在 1200 px 以内，手机上看也清楚
- 单张控制在 500 KB 以内，仓库体积要留余量
- 截图不要整屏截，只截相关内容区域

## 引用方式

```markdown
![FR3 工作空间范围](assets/fr3-work-envelope-01.png)
```

## 版权

引用论文或厂商图表时，在图下一行注明出处与链接。没有明确授权的外部图片不要直接放进来。
