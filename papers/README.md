## 写作纪律

1. **数字必须带三件套**：对照对象、测试条件、样本量。缺一个就不写进结论。
2. **不把算法的能力写成本体的能力**。跟踪进度、判断状态是模型在做，机械臂只负责执行。
3. **区分论文结论与我们的判断**。我们的复现建议单独成段，标明是推测还是实测。
