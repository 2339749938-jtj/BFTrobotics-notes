# Franka FR3 规格与选型要点

> 七轴力控协作机械臂，面向需要关节级力矩反馈与人机共融的研究场景。
> 数据整理自厂商公开规格，选型与投标前请以官方最新规格书为准。

## 关键规格

| 项目 | 参数 |
| --- | --- |
| 自由度 | 7（冗余，可在关节限位内避障） |
| 额定负载 | 3 kg（已含末端执行器与工件） |
| 工作半径 | 855 mm |
| 重复定位精度 | ±0.1 mm |
| 自重 | 约 18 kg |
| 关节力矩传感 | 每关节内置，可读实际力矩与外部力估计 |
| 控制接口频率 | 1 kHz（FCI 实时回路） |
| 安全认证 | EN ISO 13849-1 PL d, Cat 3 |
| 防护等级 | IP40 |

## 控制与接口

- **FCI（Franka Control Interface）**：C++ / Python（libfranka）直接下发关节位置、速度或力矩指令，1 kHz 闭环。做阻抗控制、力位混合、示教学习基本都走这条路。
- **ROS / ROS2**：官方与社区均有驱动封装，MoveIt 可用，但实时性不如直连 FCI。
- **Franka Desk**：浏览器端界面，用于手动示教、点位记录、系统诊断，不需要写代码。
- **可读量**：关节角度、关节力矩、外部笛卡尔力估计、碰撞状态。做零力拖动、接触任务、模仿学习的数据采集都依赖这些。

## 适合的研究方向

1. **力控与柔顺操作**：装配、插拔、打磨、擦桌子这类需要感知接触力的任务。
2. **模仿学习与 VLA 数据采集**：可编程拖拽示教 + 1 kHz 状态记录，便于构建高质量轨迹数据集。
3. **人机共融**：有 PL d Cat 3 安全认证，可在共享工作空间内运行。
4. **双臂与移动操作**：两台 FR3 组双臂，或装在移动底盘上做移动抓取。

## 常见误用

- **把重复精度当绝对精度**。±0.1 mm 是回到同一点的能力，绝对定位依赖标定。视觉引导抓取必须做手眼标定，不能直接信控制器坐标。
- **忽略负载折扣**。3 kg 是含末端的总负载，两指夹爪通常占 0.8~1 kg，实际可抓工件常只剩 2 kg 左右。选型时要按"夹爪 + 工件 + 线缆拖拽力"算。
- **期望它自带智能**。FR3 提供的是高带宽、可读力矩的执行平台，抓取策略、位姿估计、任务规划都由上层算法完成，硬件本身不做这些判断。
- **长时间高速连续运行**。协作臂不是工业臂，节拍与耐久按间歇工况设计。

## 配套建议

| 用途 | 建议配置 |
| --- | --- |
| 视觉抓取 | 腕部 RGB-D 相机 + 手眼标定（eye-in-hand） |
| 双臂协作 | 两台同型号 + 刚性龙门或移动底盘，注意两臂基座坐标统一 |
| 移动操作 | 全向移动底盘 + 48V 供电 + 急停联动 |
| 力控研究 | 六维力传感器（腕部）可作外部力估计的对照真值 |
