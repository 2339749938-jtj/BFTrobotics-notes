# PiPER 轻量机械臂

> 六轴轻量协作臂，成本和体积都低，适合桌面级实验与算法验证平台。
> 数据整理自厂商公开规格，选型与投标前请以官方最新规格书为准。

## 关键规格

| 项目 | 参数 |
| --- | --- |
| 自由度 | 6 |
| 额定负载 | 1.5 kg（含末端执行器与工件） |
| 工作半径 | 626 mm |
| 重复定位精度 | ±0.5 mm |
| 自重 | 约 4.2 kg |
| 供电 | 48 V DC |
| 安装方式 | 桌面固定 / 倒装 / 移动平台 |

## 控制与接口

- **CAN 总线直连**，可下发关节位置或位姿指令，适合嵌入自研控制链路。
- **Python SDK / ROS、ROS2 驱动**，MoveIt 可用，常规抓取与轨迹规划开箱可跑。
- 支持拖动示教，便于快速记录示范轨迹。

## 常见用途

1. **具身智能算法验证**：本体提供运动执行与状态回传，策略、位姿估计、任务规划全在上层实现。VLA、模仿学习类工作常把它作为低成本执行平台。
2. **桌面级视觉抓取实验**：单臂 + 腕部相机即可搭一套抓取验证环境。
3. **教学与课程实验**：体积小、成本低，多台并行开班不占地方。

## 选型注意

- **±0.5 mm 重复精度不适合精密装配**。做插孔、螺丝锁付这类任务要留精度余量，或改用更高精度机型。
- **负载余量小**。装完夹爪后可用负载有限，抓取大工件前先算总重。
- **臂展 626 mm 决定了工作空间**。桌面布置时注意基座位置，别让常用工位落在可达边界上。
- 与 FR3 的差别不在"精度高低"，而在**有没有关节力矩反馈**。需要力控闭环或接触力感知的任务，PiPER 不是替代方案。
